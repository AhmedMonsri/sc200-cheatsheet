# Contributing

Thanks for helping improve these notes.

## Rules

- **Official sources only.** Every fact must be traceable to Microsoft Learn or Microsoft documentation. Include the link.
- **Own words.** Paraphrase; don't copy text from Microsoft Learn.
- **Keep it short.** One-line bullets, tables for comparisons. Target 3–5 minutes of reading per module.
- **Flag uncertainty.** Mark anything you couldn't confirm with `⚠️ Unverified:`.
- **Follow the template** in [templates/module-template.md](./templates/module-template.md).

## Reporting an error

Open an issue with the file name, the incorrect statement, and the official link that shows the correct information.
